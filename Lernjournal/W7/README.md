## Probleme & Herausforderungen

Ich bin heute auf unzähligen Problemn angetreten. Ich habe vom 17.07.2025 bis Heute 24.06.2025 (Sowie auch später) keinen einzigen laufenden GitHub Actions Workflow mehr gestartet. Zuerst hat es angefangen mit Syntax Errors, dannach habe ich veraltete Terraform resourcen genutzt. Es gab auch Warning wie z.B. `.name` statt `.id` genutzt Danach sind jobs Stecken geblieben, weil sie Variablen erwartet haben, die ich nicht wusste, dass sie importiert werden müssen.

Ich habe all diese Probleme gelöst, ausser dass mit dem variabeln importieren. Diese Woche hat mir die Zeit nicht gereicht um das zumachen. Ich habe mir aber die Idee gegeben, dass ich die Variablen GitHub als secrets speichere und dann in den workflows importiere.

Ich habe wieder eingetragen, dass ich aktuell "at risk" bin, aber keine Hilfe benötige, da ich genau weiss, was zu tun ist, ich muss es nur noch zum Laufen bringen.
